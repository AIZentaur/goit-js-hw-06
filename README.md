# goit-js-hw-06

Домашнє завдання №6 з курсу JavaScript (контекст виклику функції `this`,
прототипи та класи).

## Завдання

- **Задача 1 (`js/task-1.js`)** — Акаунт користувача (рефакторинг методів
  об'єкта `customer` з використанням `this`).
- **Задача 2 (`js/task-2.js`)** — Склад товарів (клас `Storage` із приватною
  властивістю `#items`).
- **Задача 3 (`js/task-3.js`)** — Конструктор рядків (клас `StringBuilder` із
  приватною властивістю `#value`).
